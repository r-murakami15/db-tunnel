# 7. エラー処理

[目次に戻る](README.md)

エラーは接続先ごとに扱い、ほかの接続には影響させない。画面には原因と次の行動を1〜2文で出し、詳細はログに残す。

| 発生箇所 | 状況 | 画面の表示 | 動作 |
| --- | --- | --- | --- |
| 起動時 | AWS CLI / Session Manager Pluginがない | 上部に警告とインストール手順のリンク | 接続ボタンを無効化 |
| 起動時 | 設定ファイルを復号できない | 「設定を読み込めませんでした。JSONを再インポートしてください」 | ファイルを退避して空で起動 |
| 接続前 | ローカルポートが使用中 | 「ポート13306は使用中です」と、使っている接続先名（アプリ内の場合） | 中止 |
| ログイン | `aws login` が失敗・キャンセル | 「ログインできませんでした」 | 状態をエラーにする |
| ログイン | ブラウザで5分以内に完了しない | 「ログインがタイムアウトしました」 | `aws login` を終了 |
| 検索 | 踏み台・RDSが0件 | 検索条件を表示し「見つかりません。アプリ名と環境を確認してください」 | 中止 |
| 検索 | 踏み台・RDSが複数件 | 見つかった名前を表示し「複数見つかりました」 | 中止 |
| 検索 | 権限不足（AccessDenied） | 「権限がありません」とAWSのエラーコード | 中止 |
| シークレット | 取得失敗・JSONでない | 「接続情報を取得できませんでした」 | 転送は開始せず中止 |
| 転送中 | `start-session` が予期せず終了 | 「接続が切れました」と終了コード | 状態をエラーにする。自動再接続はしない |
| 転送中 | セッションのタイムアウト | 「セッションがタイムアウトしました」 | 再接続ボタンを表示 |
| 複製 | プロファイル + 環境 + アプリ名が既存と同じ | 重複している旨のエラー | 「追加」を押せなくする |
| インポート | JSONの形式不正・version未対応 | 該当箇所（行・フィールド） | ファイル全体を拒否 |

AWS CLIの呼び出しは、`start-session` と `aws login`（5分）以外は60秒でタイムアウトさせる。

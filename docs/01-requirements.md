# 2. 機能要件

[目次に戻る](README.md)

## 2.1 接続先の管理

- 接続先の追加・編集・削除ができる。項目は表示名、プロファイル、環境（dev / stg / prod）、アプリ名（検索プレフィックス）、ローカルポート。
- プロファイルは `~/.aws/config` の一覧から選べ、手入力もできる。
- 一覧はプロファイルでまとめず1本のリストで表示し、各行に表示名、「プロファイル · 状態（未接続・ログイン待ち・接続中・エラー） · :ポート」、環境バッジを表示する。
- 「プロファイル + 環境 + アプリ名」の組み合わせは重複不可とする。
- ローカルポートの初期値は13306、範囲は1024〜65535。同じポートの接続先が接続中の場合は、開始時にエラーにする（登録時の重複は警告のみ）。
- 追加は一覧の「＋」→「追加」、編集は接続先の右クリックメニュー →「編集」から行う。

### 並び順

- 一覧の並び順は利用者が決める。接続先の右クリックメニュー →「移動」→「上へ」「下へ」で1つずつ移動する。
- 先頭の接続先では「上へ」、末尾の接続先では「下へ」は押せない。検索で絞り込んでいる間は「移動」は押せない。
- 並び順は設定ファイル（接続先の配列の順序）に保存し、再起動後も保つ。
- インポートで新規に追加された接続先は末尾に入る。

### 複製

- 導線は2つ。右クリックメニュー →「複製」と、編集ダイアログの「複製」ボタン。どちらも「接続先を複製」ダイアログを開く。
- 表示名は「<元の名前> のコピー」、それ以外は複製元と同じ値を入れる。編集ダイアログから複製した場合は、保存前の入力内容を使う。
- 「プロファイル + 環境 + アプリ名」が既存と同じ間はエラーを表示し、「追加」を押せない。ポートが複製元と同じ間は「同時に接続する場合は変更してください」と案内する。
- 追加した接続先は複製元のすぐ下に入る。複製元が接続中でも、新しい接続先なので環境・ポートは変更できる。

## 2.2 接続処理

接続ボタンを押すと、次の順に処理する。各ステップの結果はログ領域に出す。

1. 入力チェック: AWS CLIとSession Manager Pluginの有無、ローカルポートが空いているかを確認する。
2. prod確認: 環境がprodなら確認ダイアログを出す。キャンセルで中止。
3. ログイン: 同じプロファイルで有効な認証がなければ `aws login --profile <p>` を実行する。ブラウザでのアカウント選択を待つ間、状態は「ログイン待ち」。有効な認証があれば省略する。
4. ユーザー確認: `aws sts get-caller-identity` の結果をログに出す。
5. 踏み台検索: `ec2 describe-instances` で踏み台を探す。0件・複数件ならエラー。
6. RDS検索: `rds describe-db-instances` でエンドポイントとシークレットARNを取得する。0件・複数件ならエラー。
7. シークレット取得: `secretsmanager get-secret-value` でユーザー名とパスワードを取得し、メモリ上だけに保持する。
8. 転送開始: `aws ssm start-session` を子プロセスとして起動し、`Port <n> opened` の出力を検知したら「接続中」にする。

AWS SDKは使わず、既存スクリプトと同じくAWS CLIを子プロセスで呼ぶ。`aws login` の認証キャッシュやプロファイル設定をそのまま使えるため。

## 2.3 停止

- 停止ボタンで、その接続先の `start-session` とその子プロセス（session-manager-plugin）を終了する。
- アプリ終了時は、接続中のすべてのセッションを終了してから閉じる。接続中があれば終了前に確認する。
- 子プロセスが予期せず終了した場合は状態を「エラー」にし、終了コードと最後の出力をログに残す。

## 2.4 ログ表示

- 接続先ごとにログを保持し、一覧で選んだ接続先のログを画面下部に表示する。
- 各行に時刻と出どころ（`[app]` = アプリ、`[ssm]` = AWS CLIの出力）を付ける。stderrは色を変える。
- 1接続先あたり最大5,000行を保持し、超えたら古い行から捨てる。
- 自動スクロール、コピー、クリア、テキストファイルへの保存ができる。
- パスワードとシークレットのJSONはログに出さない。AWS CLIの出力に含まれる場合もマスクする。

## 2.5 DB接続情報

- Host（127.0.0.1）、Port、User、Password、`mysql` 接続コマンドを表示し、それぞれコピーできる。
- パスワードは既定でマスクし、目のアイコンで一時的に表示する。
- パスワードをコピーしたら、30秒後にクリップボードの内容がまだ同じであれば消去する。

## 2.6 インポート・エクスポート

- インポートは一覧の「＋」→「JSONインポート」から行う。ファイルを選ぶと「JSONインポート」ダイアログを開き、取り込む前にプレビューと判定（新規・上書き・エラー）を表示する。
- 取り込み方法は「同じ組み合わせは上書き」「新規のみ追加」から選ぶ。エラーの行は取り込まない。新規の接続先は一覧の末尾に入る。
- エクスポートは設定画面から行い、登録済みの接続先を同じ形式のJSONで書き出す。秘密情報は含まないため平文とし、画面上でその旨を表示する。

JSONの形式は [3.2 インポート・エクスポート用JSON](02-data-design.md#32-インポートエクスポート用json) を参照。

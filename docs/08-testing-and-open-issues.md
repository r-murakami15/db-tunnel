# 9. テスト方針と未決事項

[目次に戻る](README.md)

## 9.1 テスト方針

| 種類 | 対象 | 方法 |
| --- | --- | --- |
| 単体テスト | JSONの検証、重複判定、暗号化・復号、改ざん検知、ログのマスク処理 | `cargo test` |
| 結合テスト | 接続処理の各ステップとエラー分岐 | AWS CLIをダミースクリプトに差し替えて実行（既存スクリプトのテストと同じ方式）。`aws` コマンドのパスを差し替えられるようにしておく |
| プロセス終了 | 停止・アプリ終了時に子プロセスが残らないこと | Windows・Macそれぞれで確認 |
| 実環境 | dev環境への接続、同時接続、prod確認 | リリース前に手動で確認 |
| 配布 | 新規インストール、アップデート、Macのキーチェーン確認 | 署名なしの状態で、両OSのクリーンな環境で確認 |

## 9.2 未決事項

- [ ] アップデートの配布先（`latest.json` と更新ファイルを社内から認証なしで取得できる場所）
- [ ] リポジトリの置き場所と、リリースを作る権限を持つ人
- [ ] 対応するmacOSの最低バージョン（案: 13以降）
- [ ] 初期配布用の接続先JSONを誰が作り、どこで共有するか

# 5. 画面設計

[目次に戻る](README.md)

画面は4つで、メイン画面から設定画面と2つのダイアログを開く。詳細は[画面ブループリント](https://claude.ai/artifact/JtmWA6Bs3G4svqfTbeiKyw)を参照。

| 画面 | 開き方 | 主な要素 |
| --- | --- | --- |
| ① メイン画面 | 起動時 | 上部: 前提ツールの状態、設定ボタン。左: プロファイル別の接続先一覧、検索、追加ボタン。右: 選択中の接続先の設定、DB接続情報、接続・停止・編集ボタン、ターミナル出力 |
| ② 設定・インポート | 上部の「設定・インポート」 | JSONインポート（プレビューと判定）、JSONの形式説明、エクスポート、設定ファイルの暗号化状態と保存場所、前提ツールの再チェック |
| ③ 接続先の追加・編集 | 一覧の「＋」、詳細の「編集」 | 表示名、プロファイル（選択式）、環境（3択）、アプリ名と検索条件のプレビュー、ローカルポート、削除 |
| ④ prod接続の確認 | prodの接続ボタン | 接続先・プロファイル・ポートの表示。キャンセルが初期フォーカス |

## 画面の決まりごと

- 環境バッジは文字と色の両方で区別する（dev 緑、stg 橙、prod 赤）。色だけに頼らない。
- 接続中の接続先は、編集画面でポートや環境を変更できない（停止してから変更）。
- 前提ツールが見つからない場合は、上部の表示を警告に変え、インストール手順へのリンクを出す。接続ボタンは押せなくする。
- ウィンドウの最小サイズは 960 × 640。それより狭い場合は一覧を上、詳細を下に並べる。
- 表示言語は日本語のみ。

## 画面ごとの要素（ブループリントの要約）

### ① メイン画面

- **ヘッダー**: 前提ツール（AWS CLI / Session Manager Plugin）の状態を示すピル表示と、「設定・インポート」ボタン。
- **左サイドバー**
  - 検索欄と「＋」（接続先の追加）ボタン。
  - 接続先をプロファイルごとにまとめて表示。各行に状態ドット、表示名、「状態 · :ポート」、環境バッジ。
  - フッターに設定が暗号化して保存されている旨の注記。
- **右側（選択中の接続先の詳細）**
  - タイトル（表示名）と環境バッジ、状態行（例: 「接続中（00:12:34） · localhost:13306 → RDS:3306」）。
  - 「編集」「停止」ボタン。
  - **接続先の設定** カード。
  - **DB接続情報** カード: Host / Port / User / Password をそれぞれコピーボタン付きで表示。Passwordは目のアイコンで表示切り替え。`mysql` 接続コマンド。パスワードのコピーは30秒後にクリップボードから消去される旨の注記。
  - **ターミナル出力**（ダーク背景のパネル）: 「自動スクロール」チェックボックス、「コピー」「クリア」「保存」ボタン。

### ② 設定・インポート

- メイン画面へ戻るリンク。
- **JSONインポート** カード: ファイル選択、取り込み方法のラジオボタン（同じ組み合わせは上書き / 新規のみ追加）、プレビュー表（列: 取込 / 表示名 / プロファイル / 環境 / アプリ名 / ポート / 判定）、「キャンセル」「N件を取り込む」ボタン。
- **JSON形式** カード: インポート・エクスポート用JSONの形式説明。
- **エクスポート** カード: エクスポートしたJSONは暗号化されない旨の警告。
- **設定ファイル** カード: 設定ファイルの暗号化状態と保存場所。
- **前提ツール** カード: AWS CLI / Session Manager Pluginの状態と「再チェック」ボタン。

### ③ 接続先の追加・編集ダイアログ

- 表示名
- プロファイル（セレクト）
- 環境（dev / stg / prod のセグメント型3択）
- アプリ名と、検索条件のプレビュー
  - 踏み台: `tag:Name = *<app>*-<env>*bastion*`
  - RDS: `<app>* … -<env>-mysql`
- ローカルポート
- 「削除」「キャンセル」「保存」ボタン

### ④ prod接続の確認ダイアログ

- 上端に赤い枠線、警告アイコン。
- 接続先 / プロファイル / ローカルポートを表示。
- 「キャンセル」が初期フォーカス。赤い「接続する」ボタン。

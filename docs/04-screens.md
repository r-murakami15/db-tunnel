# 5. 画面設計

[目次に戻る](README.md)

画面は6つで、メイン画面から設定画面と4つのダイアログを開く。詳細は[画面ブループリント](https://claude.ai/artifact/JtmWA6Bs3G4svqfTbeiKyw)を参照。

ブループリントの①〜④は初版の設計、⑤〜⑩は改修案（⑤ メイン画面の改修案、⑥ ＋ボタンのメニュー、⑦ 編集ダイアログ（複製ボタン）、⑧ 複製ダイアログ、⑨ JSONインポートダイアログ、⑩ 設定）。このページの番号はブループリントの番号とは別で、改修後の画面を表す。

| 画面 | 開き方 | 主な要素 | ブループリント |
| --- | --- | --- | --- |
| ① メイン画面 | 起動時 | 上部: 前提ツールの状態、設定ボタン。左: 接続先の一覧（1本のリスト）、検索、「＋」ボタン（メニュー）、右クリックメニュー。右: 選択中の接続先の設定、DB接続情報、接続・停止・再接続ボタン、ターミナル出力 | ①、⑤、⑥ |
| ② 設定 | 上部の「設定」 | エクスポート、設定ファイルの暗号化状態と保存場所、前提ツールの再チェックとパス指定 | ②、⑩ |
| ③ 接続先の追加・編集 | 「＋」→「追加」、右クリック →「編集」 | 表示名、プロファイル（選択式）、環境（3択）、アプリ名と検索条件のプレビュー、ローカルポート、削除、複製 | ③、⑦ |
| ④ prod接続の確認 | prodの接続ボタン | 接続先・プロファイル・ポートの表示。キャンセルが初期フォーカス | ④ |
| ⑤ 接続先を複製 | 右クリック →「複製」、編集ダイアログの「複製」 | ③と同じ入力項目。表示名は「<元の名前> のコピー」。重複のエラー、ポートの案内 | ⑧ |
| ⑥ JSONインポート | 「＋」→「JSONインポート」→ ファイル選択 | プレビューと判定、取り込み方法、別のファイルを選択、JSONの形式の説明（折りたたみ） | ⑨ |

## 画面の決まりごと

- 環境バッジは文字と色の両方で区別する（dev 緑、stg 橙、prod 赤）。色だけに頼らない。
- 接続中の接続先は、編集画面でポートや環境を変更できない（停止してから変更）。複製ダイアログでは、複製元が接続中でも変更できる（新しい接続先のため）。
- 前提ツールが見つからない場合は、上部の表示を警告に変え、インストール手順へのリンクを出す。接続ボタンは押せなくする。
- 右クリックメニューはキーボードでも Shift+F10 またはコンテキストメニューキーで開ける。
- ウィンドウの最小サイズは 960 × 640。それより狭い場合は一覧を上、詳細を下に並べる。
- 表示言語は日本語のみ。

## 画面ごとの要素

### ① メイン画面

- **ヘッダー**: 前提ツール（AWS CLI / Session Manager Plugin）の状態を示すピル表示と、「設定」ボタン。
- **左サイドバー**
  - 検索欄と「＋」ボタン。
  - 接続先を1本のリストで表示（プロファイルごとにまとめない）。各行に状態ドット、表示名、「プロファイル · 状態 · :ポート」、環境バッジ。並び順は利用者が決める。
  - フッターに設定が暗号化して保存されている旨の注記。
- **「＋」ボタンのメニュー**（ドロップダウン）
  - 「追加」: ③ 接続先の追加ダイアログを開く。
  - 「JSONインポート」: ファイルを選び、⑥ JSONインポートダイアログを開く。
- **接続先の右クリックメニュー**
  - 「編集」: ③ 接続先の編集ダイアログを開く。
  - 「複製」: ⑤ 接続先を複製ダイアログを開く。
  - 「移動 ▸」: 「上へ」「下へ」で1つずつ移動する。先頭では「上へ」、末尾では「下へ」を押せない。検索で絞り込んでいる間は「移動」を押せない。
- **右側（選択中の接続先の詳細）**
  - タイトル（表示名）と環境バッジ、状態行（例: 「接続中（00:12:34） · localhost:13306 → RDS:3306」）。
  - 状態に応じて「接続」「停止」「再接続」ボタン。「編集」ボタンは置かない（右クリックメニューから開く）。
  - **接続先の設定** カード。
  - **DB接続情報** カード: Host / Port / User / Password をそれぞれコピーボタン付きで表示。Passwordは目のアイコンで表示切り替え。`mysql` 接続コマンド。パスワードのコピーは30秒後にクリップボードから消去される旨の注記。
  - **ターミナル出力**（ダーク背景のパネル）: 「自動スクロール」チェックボックス、「コピー」「クリア」「保存」ボタン。

### ② 設定

- メイン画面へ戻るリンク。
- **エクスポート** カード: エクスポートしたJSONは暗号化されない旨の警告。取り込みは一覧の「＋」→「JSONインポート」から行う旨の案内。
- **設定ファイル** カード: 設定ファイルの暗号化状態と保存場所。
- **前提ツール** カード: AWS CLI / Session Manager Pluginの状態、「再チェック」ボタン、aws / session-manager-plugin のパス指定。

### ③ 接続先の追加・編集ダイアログ

- 表示名
- プロファイル（セレクト）
- 環境（dev / stg / prod のセグメント型3択）
- アプリ名と、検索条件のプレビュー
  - 踏み台: `tag:Name = *<app>*-<env>*bastion*`
  - RDS: `<app>* … -<env>-mysql`
- ローカルポート
- 「削除」「複製」（削除の隣）「キャンセル」「保存」ボタン。「複製」は保存前の入力内容で ⑤ 接続先を複製ダイアログを開く。

### ④ prod接続の確認ダイアログ

- 上端に赤い枠線、警告アイコン。
- 接続先 / プロファイル / ローカルポートを表示。
- 「キャンセル」が初期フォーカス。赤い「接続する」ボタン。

### ⑤ 接続先を複製ダイアログ

- 入力項目は ③ と同じ。表示名は「<元の名前> のコピー」、それ以外は複製元と同じ値（編集ダイアログから開いた場合は保存前の入力内容）。
- プロファイル + 環境 + アプリ名が既存と同じ間はエラーを表示し、「追加」を押せない。
- ポートが複製元と同じ間は「同時に接続する場合は変更してください」と案内する。
- 「キャンセル」「追加」ボタン。追加すると複製元のすぐ下に入る。

### ⑥ JSONインポートダイアログ

- 選んだファイル名と「別のファイルを選択」ボタン。
- 取り込み方法のラジオボタン（同じ組み合わせは上書き / 新規のみ追加）。
- プレビュー表（列: 取込 / 表示名 / プロファイル / 環境 / アプリ名 / ポート / 判定）。
- JSONの形式の説明（折りたたみ）。
- 「キャンセル」「N件を取り込む」ボタン。新規の接続先は一覧の末尾に入る。
